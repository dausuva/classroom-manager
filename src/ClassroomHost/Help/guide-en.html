Classroom Manager – teacher guide

What you need for a lesson, in the order you will meet it. Press F1 in Classroom Manager to open this page again.

Getting started

  1. Get your key. Your administrator gives you either a file (teacher-settings.json) or a key to type in. Classroom Manager offers both the first time it starts; later they are under Settings > Import teacher settings... and Settings > Host settings...
  2. Find the computers. A settings file brings them along. Otherwise choose Computers > Scan network. If a computer says connection failed because its certificate is not approved yet, tick it and choose Approve certificate...: the Host shows the certificate the computer presents and whether it is new or changed, and asks Trust and connect. Compare the fingerprint with Classroom Client Health on that computer first.
  3. Put them in a room. Tick the computers and choose Assign to room.... Only computers in a room are checked every 30 seconds.

A Teacher key runs lessons: lock, message, files, websites, wallpaper, block lists, Exam mode and power. Installing software and changing how computers are set up needs an Admin key; with a Teacher key those buttons answer that the computer refused.

The main window

  • Tabs at the top group the actions: Overview holds your chosen quick actions; the others group the remaining commands by task.
  • The list shows each computer, who is signed in and its state. A green dot is online, amber needs attention, grey is offline.
  • Tick computers first, then choose an action. The grey banner above the list always says which computers the next action will reach. All, None, Invert, Online and Offline tick them for you (they act on the computers the list shows); Ctrl+A ticks all, Esc none.
  • Quick actions in Overview are chosen in Interface settings. The banner's Actions section contains your custom buttons and is hidden when empty. More sections are alphabetical; use Arrange toolbar to reorder top rows.
  • Computers / Operations / Log switch what the lower part shows.

During a lesson

  • Lock screen... covers every monitor with your text until you press Unlock.
  • Message... shows a notice on top of what the student is doing; it can close by itself after a number of seconds.
  • Open website... and Open program... (Software tab) start the same page or program for everyone. Open website... also lets you choose the browser and whether its window opens maximized (on by default); a computer where that browser is not installed uses its default browser, and a computer with an older Client opens the page in its default browser as before.
  • Set wallpaper... (Classroom tab) puts a picture or a plain colour on the students' desktops.
  • Wake up (Computers tab) switches on computers that support it, and wakes the screen of ones that are already on.
  • Power... (Classroom tab) shuts down, restarts or signs out at the end of the lesson. Students are warned first.

Files

  • Send files... puts files into each student's Desktop, Documents or Downloads.
  • Collect files... copies the students' work to your computer, one folder per student. The originals stay where they are.
  • Recent files... lists what the students changed lately (the last 30 minutes unless you choose another time) on their Desktop and in Documents, by type: documents, images, source code and folders. Copy the files you select, or all of them, to your computer; a newer version replaces the earlier copy. Watched folders... sets other folders for a computer, and the copies are deleted after the number of days you choose.
  • Transfer history... lists what you sent and can take an unchanged file back.

Restrictions and exams

  • Websites in use... shows which sites are open right now; tick the ones to block.
  • Block websites... and Block apps... keep a list on each computer until you change it.
  • Exam mode adds a temporary set of blocked websites and programs, and can mute sound, switch cameras off and block USB drives and phones. Switching it off removes only what the exam added.

Blocking a website stops the name, not the internet: a student with a VPN can still get around it. Treat it as a deterrent.

Results and the log

  • Operations lists what you started and how it ended on each computer. Open results (or a double-click) shows the computers one by one; Retry failed repeats the action only where it did not work. Undo takes it back where it worked: it unlocks after a lock, hides a message, cancels a shutdown that is still counting down, and puts back the previous wallpaper or screen saver. Actions that cannot be taken back leave the button grey.
  • Log is the same in time order. It is also kept as a file per day; Open log folder shows them.

Settings

  • Mode: Teacher / Admin shortens or lengthens the toolbars. It does not change what your key may do.
  • Interface settings... chooses the language (English, Lithuanian or one you added under Languages...), light or dark, and your quick actions.
  • Schedules... runs lock, message, wake, time sync, shut down and other actions at set times, for all computers, a room or chosen ones. Every Host has Sync the computers' time ready but switched off; enable it to set the clocks each morning. With Catch up ticked (Sync time and Run command), a computer that was off at that time gets it as soon as it is online. Schedules run while the Host is open; tick Run schedules also when the Host is closed in Host settings... and Windows runs them while you are signed in, without the window.
  • Settings backups... puts back an earlier copy of your settings. Export configuration... saves everything, keys included, in one password-protected file to keep somewhere else.
  • Secure this lab... (under More administration and support actions) asks the computers and lists what is weaker than it should be: certificates that are not approved, computers still on the lab key itself, old Client versions, the old discovery answer, a key that is more than a year old, failed handshakes. Red is a problem, yellow a weakness; the last column names the command that fixes it. It only looks. An administrator can print the same report with ClassroomCli security.

When something does not work

What the list saysWhat it meansWhat to do
Offline (no reply)The computer is off, asleep or on another network.Use Wake up, or switch it on.
Wrong shared keyThe computer does not accept your key.Ask your administrator for the key of this room.
Online - nobody signed inThe computer is on but no student has signed in.Actions for the student (lock, message, files) wait until someone signs in.
PC is on, but the client is not reachableClassroom Client on that computer is stopped or blocked by the firewall.Run Client-Health from the setup kit on that computer; it says what is in the way.
An action answers "needs an Admin key"Your key is a Teacher key.Ask your administrator to do it, or for an Admin key.

Use Feedback (Ctrl+Shift+F) to describe a problem on the screen where it happened.
